# IDE Guide - Daily Content Automation Engine & Agentic Skills

Welcome to **IDE Guide** — the automated content generation engine and agentic skills hub for the [IDE Guide YouTube Channel (@IDEguide)](https://www.youtube.com/@IDEguide) and [IDE Guide Blogger Website](https://ideguide.blogspot.com/).

This repository automatically generates **3 daily AMP HTML blog posts** and **3 Google Flow video specifications** covering various code editors and IDEs (VS Code, Cursor, Zed, PyCharm, Neovim, Sublime Text, Windsurf, JetBrains Fleet, Replit, VSCodium, Helix, and more).

---

## 🚀 Key Features

1. **AMP (Accelerated Mobile Pages) HTML Blog Posts:**
   - Designed for seamless posting to Blogger (`ideguide.blogspot.com`).
   - Validated against AMP rules (`<amp-img>`, inline CSS `<style amp-custom>`, AMP boilerplate scripts).
   - Structured layout: Pros & Cons, Free vs Paid pricing breakdown, best target developer personas, and final verdict.

2. **Google Flow AI Video Specifications:**
   - Prompt engineering scripts for Google Flow, Runway, and Sora video generators.
   - Dual format: **YouTube Shorts (60s)** and **YouTube Long-Form Videos (3-5 min)**.
   - Includes visual scene descriptions, camera motions, ambient lighting specs, visual text overlays, and spoken audio voiceover scripts.

3. **Agentic Skill CLI Tool (`scripts/ide_guide_agent_skill.py`):**
   - On-demand generation of AMP blog posts and Google Flow video specs for any IDE or GitHub repository URL.
   - Built-in validation checks for AMP compliance and prompt completeness.

4. **100% Independent Non-Sponsorship Policy:**
   - Every generated article and video script strictly features the mandatory non-sponsorship disclosure:
     > *"Disclaimer: IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation."*

## 🛠️ Installation & Setup

### Requirements
- Python 3.10+
- `pytest` (for test suite)

```bash
# Clone the repository
git clone https://github.com/mg3994/IDE-Guide-.git
cd IDE-Guide-
```

---

## ⚡ Usage Instructions

### 1. Daily Content Generation (3 Blogs & 3 Videos)

To generate the daily package of 3 AMP blog posts and 3 video specs under `content/YYYY-MM-DD/`:

```bash
python3 scripts/generate_daily_content.py
```

### 2. On-Demand Agentic Skill CLI

To generate content on demand for a specific IDE or GitHub repository:

```bash
# Generate for a specific IDE
python3 scripts/ide_guide_agent_skill.py --ide "Cursor" --output-dir "output" --validate

# Generate for a GitHub repository
python3 scripts/ide_guide_agent_skill.py --repo "zed-industries/zed" --format "all"
```
