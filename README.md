# IDE Guide 🚀

Official content generation engine and agentic tooling for **IDE Guide**:
- 🌐 **Blogger Site**: [https://ideguide.blogspot.com/](https://ideguide.blogspot.com/)
- 🎥 **YouTube Channel**: [https://www.youtube.com/@IDEguide](https://www.youtube.com/@IDEguide)

---

## Features & Goals

1. **Daily 3 Content Packages**:
   - Automated generation of 3 AMP (Accelerated Mobile Pages) HTML blog posts formatted strictly for Blogger publishing.
   - 3 Google Flow AI video specs and scripts (9:16 Shorts & 16:9 videos) with scene-by-scene framing, lighting, audio narrative, on-screen text, pros/cons, and pricing model breakdown.

2. **Agentic Skill CLI Tool**:
   On-demand generation of custom AMP HTML blog posts and Google Flow video specs for any code editor or GitHub repository URL.

3. **Mandatory Non-Sponsorship Disclaimer**:
   Ensures complete independent evaluation across all blog posts and video specifications.

## Agentic Skill CLI Tool Usage

Generate custom blog posts and Google Flow video specifications on demand:

### Generate by IDE Name
```bash
python3 scripts/ide_guide_agent_skill.py --ide "Cursor" --pricing "Freemium ($20/mo)"
```

### Generate by GitHub Repository URL
```bash
python3 scripts/ide_guide_agent_skill.py --repo-url "https://github.com/zed-industries/zed"
```

Output files will be generated under `content/custom/` or your specified `--output-dir`.

---

## AMP HTML Validation

Validate all generated HTML posts against AMP Blogger guidelines:

```bash
python3 scripts/amp_validator.py content/
```

---

## Running Tests

Execute unit tests verifying AMP compliance, generator outputs, CLI skill, and disclaimer enforcement:

```bash
PYTHONPATH=. pytest tests/
```
