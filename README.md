# IDE Guide: Daily Automation & Agentic Content Skill Suite

Automated content generation pipeline for [IDE Guide Blogger](https://ideguide.blogspot.com/) and [IDE Guide YouTube Channel (@IDEguide)](https://www.youtube.com/@IDEguide).

## Key Features

1. **AMP (Accelerated Mobile Pages) Blogger Compliance**:
   - Generates fully compliant AMP HTML posts for Blogger.
   - Enforces valid `<amp-img>` responsive layout conventions.
   - Restricts inline styling and unauthorized script tags.
   - Automatically appends mandatory objective non-sponsorship disclaimers.

2. **Google Flow & AI Video Prompt Specifications**:
   - Creates daily 16:9 long-form YouTube video generation packages and 9:16 Shorts scripts.
   - Generates detailed visual scene prompts (camera angles, lighting, dark theme IDE UI focus).
   - Formats audio narrations highlighting editor pros, cons, pricing (Free vs Paid), and key features.

3. **3 Daily Content Packages Automation**:
   - Scheduled via GitHub Actions (`.github/workflows/daily_content_generation.yml`) to produce 3 blog posts and 3 video specs daily.
   - Keeps track of covered editors in `content/history.json` to ensure balanced topic coverage across IDEs (VS Code, Cursor, Zed, PyCharm, Neovim, Windsurf, IntelliJ, WebStorm, etc.).

4. **Agentic CLI Skill Tool**:
   - On-demand custom generator (`scripts/ide_guide_agent_skill.py`) for specific IDEs or repositories.

## Usage

### 1. Run On-Demand Agentic CLI Tool
To generate AMP HTML blog post and Google Flow video spec for any IDE or repository:

```bash
PYTHONPATH=. python3 scripts/ide_guide_agent_skill.py --ide cursor --output-dir my_output
```

### 2. Generate Daily Content Batch (3 Posts + 3 Videos)
To generate today's content package:

```bash
PYTHONPATH=. python3 scripts/generate_daily_content.py
```

### 3. Validate AMP HTML Files
To check an HTML post for Blogger AMP compliance:

```bash
python3 scripts/amp_validator.py path/to/post_amp.html
```

### 4. Run Test Suite
To run the automated tests:

```bash
PYTHONPATH=. pytest tests/
```
