## 📌 Overview

This project automates daily generation of high-quality content evaluating code editors, IDEs, and developer tools:
1. **3 Daily AMP HTML Blog Posts** formatted specifically for Google Blogger with 100% AMP compliance.
2. **3 Daily Google Flow Video Specs** tailored for generating YouTube Shorts (9:16 vertical) and YouTube long-form videos (16:9 horizontal).
3. **Agentic CLI Skill Tool** allowing instant on-demand generation for any requested IDE or GitHub repository URL.
4. **Mandatory Non-Sponsorship Disclaimers** in every generated blog post and video prompt to maintain objective transparency.

## ⚡ Quick Start & Skill Usage

### 1. On-Demand Content Generation (CLI Skill)

You can generate an AMP blog post and Google Flow video prompt spec on-demand for any IDE name or GitHub repository URL:

```bash
# Generate for a specific IDE name
PYTHONPATH=. python3 scripts/ide_guide_agent_skill.py --ide "Cursor" --outdir output/

# Generate for a GitHub repository URL
PYTHONPATH=. python3 scripts/ide_guide_agent_skill.py --ide "https://github.com/zed-industries/zed" --outdir output/
```

### 2. Run Daily Content Generator

To generate today's package of 3 AMP blog posts and 3 Google Flow video specs:

```bash
PYTHONPATH=. python3 scripts/generate_daily_content.py
```

### 3. Validate AMP HTML Output

To verify that an HTML blog post meets AMP Blogger specifications:

```bash
PYTHONPATH=. python3 scripts/amp_validator.py content/2026-10-25/post_1_visual_studio_code.html
```
