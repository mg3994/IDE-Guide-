# IDE Guide 🚀

Automated content generation suite for **IDE Guide**, producing daily AMP HTML blog posts for Blogger and Google Flow video specifications/scripts for YouTube.

- **YouTube Channel**: [https://www.youtube.com/@IDEguide](https://www.youtube.com/@IDEguide)
- **Blogger Website**: [https://ideguide.blogspot.com/](https://ideguide.blogspot.com/)

---

## 🌟 Key Features

1. **AMP (Accelerated Mobile Pages) HTML Blog Posts**:
   - Valid AMP HTML format designed for Google Blogger.
   - Fully optimized for mobile speed, zero external heavy JS, inline `<style amp-custom>`, and canonical linkage.
   - Comprehensive reviews featuring IDE overviews, Pros & Cons, Free vs Paid pricing tier breakdowns, and target audience recommendations.

2. **Google Flow Video Specifications & Visual Scripts**:
   - Custom video prompts for AI video generators (e.g., Google Flow) to produce high-engagement videos and YouTube Shorts (`9:16` and `16:9`).
   - Includes cinematographic camera angles, studio dark mode lighting, timing cues, and narration audio scripts.

3. **Daily Automated Content Pipeline (3 Videos & 3 Blog Posts per Day)**:
   - Automated script (`scripts/generate_daily_content.py`) discovers novel IDEs/editors via GitHub Search API and curated registries.
   - Output structured into `content/YYYY-MM-DD/` with 3 AMP posts and 3 video specs daily.
   - Tracks covered tools in `content/history.json` to eliminate repeated reviews.
   - Scheduled via GitHub Actions (`.github/workflows/daily_content_generation.yml`) daily at 21:30 UTC.

4. **Agentic CLI Skill Tool (`scripts/ide_guide_agent_skill.py`)**:
   - Enables agents or command-line users to generate custom AMP HTML posts and Google Flow video specs on demand for any specified IDE or GitHub repository URL.

5. **Mandatory Non-Sponsorship Disclaimer**:
   - Every piece of generated content includes the exact non-sponsorship disclaimer:
   > `Disclaimer: IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation.`

## 🛠️ Usage Instructions

### 1. Run Daily Content Generator
To manually trigger the generation of 3 daily video specs and 3 AMP HTML blog posts:

```bash
python3 scripts/generate_daily_content.py
```

### 2. Run Agentic Skill CLI for a Specific IDE or Repository
To generate custom content for a specific IDE name or GitHub repository URL:

```bash
# Generate by IDE name
python3 scripts/ide_guide_agent_skill.py --ide "Zed Editor"

# Generate by GitHub Repository URL
python3 scripts/ide_guide_agent_skill.py --repo "https://github.com/zed-industries/zed"
```

### 3. Run Unit Tests
To run the full test suite and verify AMP HTML compliance and history tracking:

```bash
pytest tests/
```
