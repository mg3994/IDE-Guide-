# IDE Guide 🚀

Official content generation engine and agentic skills for **IDE Guide**.

- **Blogger Website**: [https://ideguide.blogspot.com/](https://ideguide.blogspot.com/)
- **YouTube Channel**: [@IDEguide](https://www.youtube.com/@IDEguide)

---

## Overview

IDE Guide produces objective, developer-focused evaluations, comparisons, and video specifications covering diverse IDEs, code editors, and developer tools.

Every day, the platform generates:
1. **3 AMP HTML Blog Posts** formatted specifically for fast, mobile-optimized publishing on Blogger.
2. **3 Google Flow Video Specifications** (including visual camera prompts, lighting specs, scene breakdowns, and narration voiceover scripts) tailored for YouTube videos (16:9) and YouTube Shorts (9:16).

## Quick Start & Usage Guide

### 1. Daily Content Generator
To generate today's 3 content packages (AMP blog posts + Google Flow video specs) and record them in `content/history.json`:

```bash
python3 scripts/generate_daily_content.py
```

### 2. Agentic CLI Skill (On-Demand Content Generation)
To generate a custom AMP blog post and Google Flow video spec for a specific IDE or GitHub repository URL:

```bash
# By IDE Name
python3 scripts/ide_guide_agent_skill.py --ide "Cursor Editor"

# By Repository URL
python3 scripts/ide_guide_agent_skill.py --repo "https://github.com/helix-editor/helix"
```

### 3. AMP Validation
To validate any HTML file against AMP standards and non-sponsorship disclaimer compliance:

```bash
python3 scripts/amp_validator.py content/2026-10-22/post-1-vscode/blog_post.amp.html
```
