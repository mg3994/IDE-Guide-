Helix: Post-Modern Modal Text Editor in Rust

Pricing: Free & Open Source

Primary Tech Stack: Rust, Systems, Command-line, Polyglot

Platform Support: Linux, macOS, Windows, Terminal

Overview & Why Use It

Helix is a terminal-based modal text editor inspired by Neovim and Kakoune. Written in Rust, it comes with zero-config LSP support, tree-sitter syntax highlighting, and selection-first editing built right in.

Key Features & Language Ecosystem

  • Selection-first modal editing (manipulate selections before running actions)
  • Built-in Language Server Protocol (LSP) support with zero plugin config required
  • Tree-sitter integration for fast syntax tree navigation and structural editing
  • Pure terminal application with truecolor and mouse support

How to Get Started

  1. Install Helix via homebrew (`brew install helix`) or cargo (`cargo install --path helix-term`).
  2. Run `hx --health` to verify language server dependencies for your active languages.
  3. Launch Helix in any directory (`hx .`).
  4. Run through the built-in interactive tutor by typing `hx --tutor`.

Free vs. Paid Breakdown

Helix is 100% free and open source released under the MPL-2.0 license.

Verdict & Best Use Cases

Perfect for terminal enthusiasts who want modern features like LSP and Tree-sitter without managing complex plugin configurations.
