Overview & Why Use It

Pine is a newly emerging code editor hosted at https://github.com/batonogov/pine. A native macOS code editor for CLI-agent workflows. Split editor and terminal panes, a cross-project Agent Inbox, private notifications, LSP, Git context — zero Electron.

How to Get Started

  1. Clone the repository from GitHub: `git clone https://github.com/batonogov/pine`.
  2. Review setup instructions in the official README.
  3. Build binary from source or download latest release package.
  4. Launch Pine in your project workspace.
