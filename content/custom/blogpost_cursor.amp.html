Cursor - Features, Pricing & Developer Verdict

1. Overview

An AI-first code editor built as a fork of Visual Studio Code, featuring deep LLM integration with Claude 3.5 Sonnet, inline AI edits, and codebase indexing.

2. Pricing Tier & Licensing (Paid vs Free)

Pricing Structure: Freemium (Free hobby tier with basic requests, $20/month Pro tier for fast premium queries).

3. Key Strengths & Pros

  • Native integration with Claude 3.5 Sonnet and GPT-4o for inline editing.
  • Full compatibility with VS Code extensions and keybindings.
  • Smart multi-file code indexing and codebase-aware AI suggestions.

4. Limitations & Cons

  • Requires a monthly subscription for heavy AI query workloads.
  • Closed-source core backend component.

5. Recommendation & Best Target Audience

Best for developers seeking cutting-edge AI pair-programming and seamless VS Code transition.
