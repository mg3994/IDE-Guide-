# AMP (Accelerated Mobile Pages) Guidelines for Blogger Posts

Target Website: [IDE Guide Blogger](https://ideguide.blogspot.com/)

## 1. Overview
All blog post content generated for IDE Guide must comply with Google AMP (Accelerated Mobile Pages) HTML specifications to ensure lightning-fast mobile rendering, high SEO ranking, and compliance with modern web performance standards.

## 2. Mandatory Non-Sponsorship Disclaimer
Every blog post **MUST** end with the following exact disclaimer in a distinct container or blockquote:

> **Disclaimer:** IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation.

## 3. Core AMP HTML Rules
1. **Root Tag**:
   - Must use `<html ⚡>` or `<html amp>`.
2. **Head Elements**:
   - Must contain `<meta charset="utf-8">`.
   - Must contain `<meta name="viewport" content="width=device-width,minimum-scale=1,initial-scale=1">`.
   - Must include the AMP runtime script: `<script async src="https://cdn.ampproject.org/v0.js"></script>`.
   - Must include AMP boilerplate style inside `<style amp-boilerplate>` (or Blogger template compatible boilerplate).
3. **Styling**:
   - Custom CSS **MUST** be inside a single `<style amp-custom>` tag in the `<head>`.
   - Total CSS size must not exceed **75KB**.
   - No inline `style="..."` attributes are allowed on HTML tags.
   - Do not use `!important` declarations.
4. **Media Tags**:
   - Standard `<img>` tags are **forbidden**.
   - Must use `<amp-img src="..." width="..." height="..." layout="responsive" alt="..."></amp-img>`.
   - Always supply explicit `width` and `height` attributes to prevent layout shifts.
   - Audio and video must use `<amp-audio>` and `<amp-video>` or `<amp-youtube>`.
5. **Scripts and Elements**:
   - Custom JavaScript (`<script>` tags) is strictly prohibited unless loading official AMP components (e.g., `<script async custom-element="amp-youtube" src="https://cdn.ampproject.org/v0/amp-youtube-0.1.js"></script>`).
   - Deprecated HTML tags like `<font>`, `<center>`, `<marquee>`, `<frame>` are strictly forbidden.

## 4. Blog Post Structure Requirements
Each AMP blog post generated by IDE Guide must include:
1. **Title & Header**: Highlighting the IDE name, license type (Free / Paid / Freemium), and primary use case.
2. **Key Specifications & Features**: Structured list or comparison matrix.
3. **Pros & Cons Analysis**: Clear objective evaluation of strengths and weaknesses.
4. **Ideal User Persona / Recommendations**: Clear guidance on who should use this editor and alternatives.
5. **Call to Action**: Encouraging readers to check out the YouTube channel `@IDEguide` for visual reviews and video walkthroughs.
6. **Mandatory Non-Sponsorship Disclaimer**.
