# Google Flow Video Specification Guidelines

This document details the video prompt, framing, lighting, camera motion, and script standards for generating YouTube content (@IDEguide) using Google Flow and related video creation tools.

## Content Structure

Each daily video specification generated by IDE Guide must cover:
1. **Overview & Pitch**: What the IDE/editor is and its primary value proposition.
2. **Pricing Model**: Clear distinction whether it is Free, Freemium, Open Source, or Paid.
3. **Pros & Cons (Good & Bad)**: Highlighting key developer features, performance, extension ecosystem, as well as limitations or drawbacks.
4. **Target Audience & Verdict**: Recommendation on who should use it and when it is the best choice.
5. **Non-Sponsorship Disclosure**: Explicit statement that the content is unbiased and unsponsored.

## Google Flow Prompt Standards

When crafting video generation specifications for Google Flow or similar AI video tools:

### Visual Prompting
- **Framing**: Specify camera framing clearly (e.g., `Ultra close-up of dark mode IDE code editor with syntax highlighting`, `Medium shot of developer workspace with dual monitors`).
- **Lighting**: Detail lighting temperature and style (e.g., `Soft neon blue studio backlight`, `Warm desk lamp ambient illumination`, `Cinematic dark mode glow`).
- **Camera Motion**: Define dynamic camera movements (e.g., `Slow cinematic pan left to right across terminal output`, `Smooth push-in shot toward active code completion popover`).
- **Resolution & Aspect Ratio**: 16:9 widescreen for main YouTube videos, 9:16 vertical orientation for YouTube Shorts.

### Script & Voiceover
- **Tone**: Professional, energetic, objective, and developer-focused.
- **Pacing**: Clear voiceover script timed per scene with accompanying visual prompts and on-screen text overlays.

## Mandatory Non-Sponsorship Disclaimer

Every video specification and script must include the exact disclaimer text:

> **Disclaimer:** IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation.
