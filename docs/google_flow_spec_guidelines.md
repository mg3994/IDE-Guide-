# Google Flow AI Video Prompt & Specification Guidelines

This document provides specifications for generating video creation prompts and voiceover scripts designed for Google Flow AI and visual video generation tools for the `@IDEguide` YouTube channel.

## 1. Video Requirements

- **Daily Output Target**: 3 videos per day (matching the 3 daily blog posts).
- **Dual Format Specification**:
  1. **YouTube Long-form (16:9 Landscape)**: 2-3 minute comprehensive visual review.
  2. **YouTube Shorts / Reels (9:16 Vertical)**: 45-60 second fast-paced highlight breakdown.

## 2. Google Flow Visual Prompt Structure

Each video scene prompt for Google Flow AI must define explicit visual parameters to ensure high cinematic quality and consistency across AI-generated scenes:

- **Subject & Action**: Detailed description of the IDE user interface, code snippet animations, or developer workspace.
- **Camera Movement**: Specific camera motions such as `Smooth slow push-in`, `Pan left to right across code editor UI`, `Macro tilt down on glowing syntax highlighting`.
- **Lighting & Color Palette**: Visual aesthetic setup, e.g., `Dark mode theme with neon blue and cyan accent glow`, `Volumetric studio rim lighting`, `Clean minimalist workspace lighting`.
- **Atmosphere & Style**: Photorealistic 8K render, clean UI screen recording aesthetic, modern tech workspace background.

## 3. Video Structure & Scene Template

Each video specification package generated by IDE Guide must include scene-by-scene timing and prompt details:

### Scene Breakdown Structure

1. **Scene 1: Hook & Introduction (00:00 - 00:15)**
   - **Visual Prompt**: Macro camera shot sweeping across a modern laptop screen displaying code in dark mode with glowing syntax highlighting, subtle depth of field blur in background.
   - **Voiceover**: "Is [IDE Name] worth switching to in 2025? Here is what you need to know in 60 seconds."

2. **Scene 2: Core Highlights & Key Features (00:15 - 00:45)**
   - **Visual Prompt**: Split composition showing AI code autocompletion speed and multi-cursor editing in [IDE Name], hyper-realistic desk setup with soft ambient lighting.
   - **Voiceover**: "Here are the top features that make [IDE Name] stand out..."

3. **Scene 3: Pros, Cons & Pricing Tier (00:45 - 01:15)**
   - **Visual Prompt**: Animated infographic overlay showing Free vs Paid features, pros list on left, cons list on right over a sleek gradient glassmorphic background.
   - **Voiceover**: "[IDE Name] offers [Free/Paid/Freemium] tiers. Here are the pros and cons..."

4. **Scene 4: Final Recommendation & Outro (01:15 - 01:30)**
   - **Visual Prompt**: Developer closing laptop with satisfied expression, camera panning back to reveal modern home office setup with dual monitors.
   - **Voiceover**: "Who should use [IDE Name]? Check out our full AMP review on ideguide.blogspot.com and subscribe to @IDEguide for daily code editor reviews!"

## 4. Mandatory Non-Sponsorship Disclaimer

Every video script package must include the mandatory verbal voiceover and visual lower-third disclaimer text:
> "Disclaimer: IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation."
