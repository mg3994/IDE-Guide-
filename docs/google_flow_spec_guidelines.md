# Google Flow Video Spec Guidelines for IDE Guide

This document defines the prompt structure, visual specifications, camera movements, lighting, scene breakdown, and script formats used for generating high-quality YouTube videos and Shorts for **IDE Guide** on [https://www.youtube.com/@IDEguide](https://www.youtube.com/@IDEguide).

---

## 1. Video Formats & Aspect Ratios

- **YouTube Standard Videos**: 16:9 aspect ratio (1920x1080 resolution), 60 FPS target.
- **YouTube Shorts**: 9:16 aspect ratio (1080x1920 resolution), vertical orientation optimized for mobile feed.

---

## 2. Visual Prompt & Aesthetics Specification

Google Flow video prompts require explicit details regarding camera angles, lighting, aesthetics, and action sequences:

### Visual Aesthetics & Lighting
- **Style**: Modern dark mode code editor interface with vibrant syntax highlighting (cyan, magenta, electric yellow, emerald green).
- **Lighting**: Clean studio lighting with soft neon edge lighting (cool blue and deep violet backlight) reflecting off matte black developer desk setup.
- **Environment**: Clean, high-tech developer workstation with sleek mechanical keyboard, modern high-resolution monitor displaying the IDE interface.

### Camera Movements & Framing
- **Wide Shots**: Establishing shot of the workspace and monitor running the IDE interface.
- **Close-ups**: Smooth macro zoom on syntax highlighting, auto-completion popups, or terminal outputs.
- **Panning & Tracking**: Gentle left-to-right tracking shots following code cursor movement or sidebar extension browsing.

---

## 3. Scene Breakdown & Timing (60-second Short / Video Template)

| Scene | Duration | Visual Prompt & Framing | Narration / Script |
|-------|----------|-------------------------|--------------------|
| **Scene 1: Hook** | 0s - 7s | Close-up fast zoom on IDE startup speed and crisp UI. | "Looking for the ultimate code editor? Let's break down [IDE Name] in 60 seconds!" |
| **Scene 2: Pros (The Good)** | 7s - 25s | Medium tracking shot highlighting key features, extension ecosystem, AI completion. | "The Good: Lightning-fast startup, incredible built-in AI completion, and seamless git integration." |
| **Scene 3: Cons (The Bad)** | 25s - 40s | Macro shot showing memory usage or complex config files. | "The Bad: Heavy RAM footprint on large monorepos and a steeper learning curve for advanced keybindings." |
| **Scene 4: Pricing** | 40s - 50s | Clean infographic visual overlay showing Free vs Paid tier breakdown. | "Pricing: Completely free and open-source for personal use, with optional paid pro features." |
| **Scene 5: Verdict & Disclaimer** | 50s - 60s | Wide shot of workspace with text overlay: "Not Sponsored - Objective Review". | "Verdict: Best for full-stack web developers. Check out the full review on ideguide.blogspot.com!" |

Every video script and visual specification must include the non-sponsorship disclaimer:

> **Disclaimer**: IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation.
