# Google Flow Video Generation Spec & Guidelines

This document outlines the visual prompt structure, camera settings, lighting, style parameters, and voiceover formatting required for generating automated video content for **IDE Guide** YouTube channel using Google Flow (or compatible AI video generation tools).

---

## 1. Visual Prompt Structure Guidelines

Each scene description prompt for Google Flow must adhere to the following standard template:

`[Subject / Scene Action] + [Environment / Background] + [Lighting & Atmosphere] + [Camera Movement & Framing] + [Style & Rendering Parameters]`

### Components:
- **Subject / Scene Action**: Specific developer interface action, high-contrast code highlighted on screen, 3D floating keycaps, glowing cursor navigating code blocks, or macro developer environment setup.
- **Environment / Background**: Sleek dark-mode workspace, minimalist ambient desk setup, futuristic neon cyberpunk glow, soft bokeh background office, or abstract digital wireframes.
- **Lighting & Atmosphere**: Soft volumetric rim lighting, ambient dark blue/purple neon reflections, high-tech glow, crisp studio accent lighting.
- **Camera Movement & Framing**: Slow cinematic push-in, subtle pan right, macro 45-degree angle close-up on line of code, smooth top-down overhead shot.
- **Style & Rendering Parameters**: 4K resolution, photorealistic cinematic lighting, 60fps, clean UI render, minimal visual noise, high contrast tech aesthetic.

---

## 2. Aspect Ratio & Technical Formats

### Short-Form Video (YouTube Shorts / Reels / TikTok)
- **Aspect Ratio**: 9:16 (Vertical, 1080x1920)
- **Duration**: ~60 seconds total (5-7 scenes, ~8-10 seconds per scene)
- **Visual Pace**: Fast cuts, high impact, bold floating text overlays.

### Long-Form Video (YouTube Standard)
- **Aspect Ratio**: 16:9 (Horizontal, 1920x1080 / 3840x2160)
- **Duration**: 3 to 5 minutes (8-12 scenes / chapters)
- **Visual Pace**: Smooth transitions, detailed UI callouts, chapter intro cards, step-by-step walkthrough visual background animations.

---

## 3. Voiceover & Audio Guidelines
- **Tone**: Energetic, direct, technical, objective, zero fluff.
- **Script Pace**: ~130-150 words per minute.
- **On-Screen Captions**: Key takeaway highlights synchronized with voiceover cues.

---

## 4. Standard Disclaimer Requirement
Every video description must conclude with the exact non-sponsorship disclaimer:
> *"Disclaimer: IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation."*
