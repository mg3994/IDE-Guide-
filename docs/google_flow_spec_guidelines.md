# Google Flow & Video Generation Specifications for IDE Guide

This document defines the script formatting, prompt specifications, visual framing, and audio/voice instructions for generating daily video content and Shorts for the **IDE Guide** YouTube channel ([@IDEguide](https://www.youtube.com/@IDEguide)).

## 1. Video Specifications Overview

- **Daily Schedule**: 3 Videos / Shorts generated per day.
- **Aspect Ratio**: 9:16 (Shorts/Vertical) or 16:9 (Full YouTube Reviews).
- **Duration**:
  - **Shorts**: 45 - 60 seconds (fast-paced, high engagement).
  - **Standard Video**: 3 - 5 minutes (detailed walkthrough).

## 2. Google Flow Prompt Structure

Every video specification document generated for Google Flow / AI Video Generators must contain structured visual and audio prompts divided into explicit scenes:

### Scene Structure
- **Scene ID & Timecode**: e.g. `Scene 1 (0:00 - 0:08)`
- **Visual Prompt**: Detailed AI camera prompt (e.g., *Macro shot of a developer dark-mode code editor displaying glowing Rust syntax, sleek camera pan right, high cinematic lighting*).
- **On-Screen Text Overlay**: Clear title card or bullet point text.
- **Voiceover Script (Audio Prompt)**: Word-for-word narrative spoken in high-energy technical tone.
- **B-Roll / Code Snippet Prompt**: Relevant UI screenshot, terminal command execution, or benchmark graph prompt.

## 3. Video Content Guidelines

1. **Hook (0-5s)**: Bold question or feature showcase (e.g., *"Is Cursor really replacing VS Code in 2026?"*).
2. **Pros & Features (5-25s)**: Quick highlight of top 3 standout capabilities (e.g., AI autocomplete, tree-sitter performance, zero-latency scrolling).
3. **Cons & Gotchas (25-40s)**: Honest summary of pricing, telemetry, or resource consumption.
4. **Pricing & Best For (40-50s)**: Clear verdict on free vs paid tier and ideal user persona.
5. **Call to Action & Non-Sponsorship Disclaimer (50-60s)**: Direct viewers to [ideguide.blogspot.com](https://ideguide.blogspot.com/) for full comparison.

## 4. Mandatory Non-Sponsorship Disclaimer

Every video specification and script must conclude with:

> **Disclaimer:** IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation.
