# Google Flow Video Specification Guidelines

This document outlines the standard specification and prompt engineering structure for generating AI videos using **Google Flow** (and other AI video synthesis tools like Runway Gen-3, Sora, Pika, Kling, Luma Dream Machine) for the **IDE Guide** YouTube channel (`https://www.youtube.com/@IDEguide`).

---

## Overview

IDE Guide publishes **3 videos daily** (combination of YouTube Shorts and long-form reviews/comparisons) showcasing code editors, IDEs, extensions, and AI coding assistants.

To maintain high visual quality, consistency, viewer retention, and engagement, all video specifications generated by our automated scripts and agentic skills MUST adhere to these prompt engineering guidelines.

---

## Video Specifications & Technical Standards

### 1. Aspect Ratios & Formats
- **Long-Form Reviews (YouTube)**: `16:9` widescreen (1920x1080 / 3840x2160), 60 FPS target.
- **Shorts / Reels / TikTok**: `9:16` vertical (1080x1920), 60 FPS target.

### 2. Camera Framing & Composition
- **Hero Intro / Host Framing**: Medium close-up (MCU), eye-level camera angle, cinematic shallow depth of field (f/1.8).
- **IDE Code Showcase**: Direct screen recording style mock, high-contrast dark theme (e.g. Catppuccin, One Dark Pro, Dracula), sharp crisp typography, subtle code syntax highlighting in motion.
- **B-Roll & Visual Transitions**: Dynamic slow pan (left-to-right or right-to-left), gentle zoom-in macro shot of keypresses or mechanical keyboard lighting, high-tech ambient backdrop with soft neon ambient lighting (blue/purple/teal studio glow).

### 3. Lighting & Aesthetic Style
- **Lighting**: Cinematic studio rim lighting, soft key light, dark minimalist dark-mode developer aesthetic with vibrant neon accent lighting (cyan `#00f3ff`, purple `#8a2be2`, neon green `#00ff66`).
- **Texture & Vibe**: Sleek, modern, ultra-clean tech laboratory or cozy modern developer workstation.

### 4. Voiceover & Audio Sync
- **Pacing**: Confident, articulate, fast-paced technical narrator (140 - 160 words per minute).
- **Voice Style**: Engaging tech enthusiast, balanced and objective tone.
- **Audio Cue Structure**:
  - `[00:00 - 00:03]` Hook: Visual punch + direct question.
  - `[00:03 - 00:20]` Overview & Key Features (Pros).
  - `[00:20 - 00:35]` Critical Assessment (Cons & Weaknesses).
  - `[00:35 - 00:50]` Pricing Breakdown (Free Tier vs Paid Subscriptions).
  - `[00:50 - 00:60]` Final Recommendation & Outro / Call-To-Action (CTA).

## Prompt Structure for Google Flow AI Video Engine

When formatting prompt specifications for Google Flow or similar text-to-video engines, use structured prompts with explicit visual, camera, motion, and lighting directives:

### Example Google Flow Prompt Format:
```json
{
  "scene_number": 1,
  "start_time": "00:00",
  "end_time": "00:05",
  "prompt": "Cinematic medium shot of a modern dark-mode IDE code editor interface glowing softly on a sleek curved monitor in a dimly lit studio. Smooth slow pan camera motion, soft teal cyan rim lighting, crisp 4k detail, ultra-sharp code syntax highlighting, professional developer desk environment.",
  "camera_motion": "slow_pan_right",
  "framing": "medium_close_up",
  "aspect_ratio": "16:9",
  "voiceover_text": "Is Cursor really the AI code editor that will replace VS Code in 2026? Let's break down the pros, cons, and pricing."
}
```
