# Google Flow & AI Video Prompt Specifications Guidelines

Target Channel: [IDE Guide YouTube Channel](https://www.youtube.com/@IDEguide)

## 1. Overview
IDE Guide produces 3 high-impact video scripts and prompt specifications daily for YouTube (including Long-Form Reviews and YouTube Shorts / Reels). These specifications are designed for consumption by AI video generators (such as Google Veo / Google Flow, Runway Gen-3, Luma Dream Machine) and automated voiceover / text-to-speech tools.

## 2. Mandatory Non-Sponsorship Disclaimer
Every video specification and voiceover script **MUST** include the exact non-sponsorship disclaimer at the end of the voiceover transcript and in the description metadata:

> **Disclaimer:** IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation.

## 3. Video Structure & Formats

### A. YouTube Shorts Format (60 Seconds Max / Vertical 9:16)
- **Aspect Ratio**: 9:16 (1080x1920)
- **Target Duration**: 45 - 60 seconds
- **Pacing**: Fast-paced, high retention hook in the first 3 seconds
- **Scene Breakdown**:
  - **00:00 - 00:05 Hook**: Attention-grabbing visual & statement comparing the IDE or presenting its headline feature.
  - **00:05 - 00:20 Pros & Key Features**: Key advantages, UI highlight, AI capabilities or performance stats.
  - **00:20 - 00:35 Cons & Pricing**: Limitations, pricing tiers (Free vs Paid), and memory footprint.
  - **00:35 - 00:50 Verdict & Recommendation**: Who should switch or stay.
  - **00:50 - 00:60 CTA & Disclaimer**: Call to subscribe to @IDEguide and non-sponsorship disclaimer.

### B. YouTube Long-Form Format (3 - 5 Minutes / Horizontal 16:9)
- **Aspect Ratio**: 16:9 (1920x1080)
- **Target Duration**: 180 - 300 seconds
- **Scene Breakdown**:
  - **Scene 1: Introduction & Overview**: IDE launch, target ecosystem, license model.
  - **Scene 2: Key Features & Strengths**: Code completion, extension ecosystem, performance benchmarks.
  - **Scene 3: Limitations & Drawbacks**: Memory overhead, missing features, setup complexity.
  - **Scene 4: Pricing & Licensing Breakdown**: Free community tier vs Enterprise / Paid plans.
  - **Scene 5: Final Verdict & Comparison**: Comparative matrix vs alternatives (VS Code, JetBrains, Cursor, Zed, etc.).
  - **Scene 6: Channel CTA & Non-Sponsorship Disclaimer**.

## 4. Google Flow & AI Visual Prompt Guidelines
For every scene, prompt specifications should include detailed visual directives:
1. **Camera Framing & Motion**: e.g., "Macro close-up, 35mm lens, smooth slow push-in towards dark mode IDE code editor display."
2. **Lighting & Mood**: e.g., "Cinematic neon cyber-blue lighting, soft ambient glow, modern developer workspace background."
3. **Subject & Action**: e.g., "Developer typing python code on a sleek mechanical keyboard with glowing RGB backlit keys, reflecting syntax highlighting on screen."
4. **Style & Color Palette**: Dark theme UI, sleek modern aesthetic, deep slate blue, electric violet, crisp text.
5. **On-Screen Text Callouts**: Clean typography specifying headline specs, pricing badges, or pros/cons checkmarks.
