# Google Flow & AI Video Prompt Specifications Guidelines

This document outlines the visual, auditory, and structural specifications for generating video prompts and scripts for YouTube (@IDEguide - [https://www.youtube.com/@IDEguide](https://www.youtube.com/@IDEguide)) using Google Flow and other generative video AI tools.

## Channel Mission & Video Daily Output

- **Daily Output**: 3 videos per day (Shorts / Video specs).
- **Format Specs**:
  - Vertical (9:16 aspect ratio, 1080x1920) for YouTube Shorts / Reels.
  - Landscape (16:9 aspect ratio, 1920x1080) for full YouTube reviews.

## Google Flow Prompt Structure

Each video script must define structured prompt blocks compatible with Google Flow video generation:

1. **Scene Framing & Camera**:
   - Explicit camera movements (e.g., "Cinematic slow zoom-in", "Macro pan across mechanical keyboard and code screen").
   - Aspect ratio and resolution flags (`9:16`, `1080p`, `60fps`).

2. **Lighting & Visual Aesthetic**:
   - Lighting style (e.g., "Dark mode neon cyber-ambient blue and purple rim light", "Clean studio lighting with soft overhead diffuser").
   - Code editor interface focus with highlighted syntaxes.

3. **Audio & Script Breakdown**:
   - Narration voiceover (clear, engaging, fast-paced technical tone).
   - On-screen captions / text overlays for key Pros & Cons, pricing tier (Free vs Paid).

4. **Required Video Content Sections**:
   - Hook (0-3s): Attention-grabbing question or visual setup.
   - Core Features & Interface Overview (3-15s).
   - Pros (The Good) vs Cons (The Bad) (15-40s).
   - Pricing & Verdict: Is it Free, Paid, or Freemium? Who is it best for? (40-55s).
   - Non-sponsorship Disclaimer & Call to Action (55-60s).

5. **Mandatory Non-Sponsorship Disclaimer**:
   > Disclaimer: IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation.
