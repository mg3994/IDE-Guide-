# Google Flow Video & Shorts Prompt & Script Guidelines for @IDEguide

This document provides visual guidelines, prompt specifications, framing rules, lighting standards, and script structures for generating video prompts for Google Flow and other AI video generation tools.

## Channels & Platforms
- **YouTube Channel**: [@IDEguide](https://www.youtube.com/@IDEguide)
- **Blogger Website**: [IDE Guide](https://ideguide.blogspot.com/)

---

## 1. Visual & Cinematic Directives for Google Flow

### Framing & Aspect Ratios
- **YouTube Shorts / Vertical Reels**: 9:16 aspect ratio (1080x1920). Center subjects in safe zones to ensure no text overlay clipping.
- **YouTube Main / Horizontal Videos**: 16:9 aspect ratio (3840x2160 / 1920x1080).
- **Camera Movement**: Cinematic pan, slow push-in, floating macro focus on code syntax and UI keybindings.

### Lighting & Atmosphere
- **Theme**: Dark mode developer aesthetic. High contrast, neon accent glows (cyber cyan `#00f3ff`, electric purple `#7000ff`, vibrant emerald `#00ff88`).
- **Lighting**: Soft key lighting with dramatic backlight/rim light on sleek workstation setups and screen displays.

### Visual Prompts Format
Every video prompt generated for Google Flow must follow this structured template:
```
[Style]: Cinematic dark mode developer setup, 8K, high detail.
[Subject]: Macro close-up of [IDE Name] interface displaying code syntax highlighting in [Language].
[Lighting]: Soft ambient dark room with cyan/purple neon LED backlighting.
[Camera]: Smooth horizontal dolly zoom onto editor feature [Feature Name].
[Atmosphere]: Modern, professional software engineering environment.
```

---

## 2. Audio & Narration Specifications

- **Tone**: Authoritative, concise, objective, developer-focused, engaging.
- **Pacing**: Fast-paced for Shorts (140-160 words/min); balanced for Long-form (120-140 words/min).
- **Sound Effects (SFX)**: Keyboard key-clicks, futuristic interface swooshes, subtle ambient electronic pad.

---

## 3. Required Content Structure for IDE Reviews

Every daily video package must cover:
1. **Introduction**: Brief overview of the IDE/Code Editor and primary target developer audience.
2. **Key Features & Pros**: Standout developer workflow capabilities, extension ecosystem, AI integration, speed.
3. **Cons & Weaknesses**: Performance overhead, memory usage, learning curve, missing features.
4. **Pricing & Licensing**: Clear breakdown of Free vs. Paid tiers, open-source vs. proprietary, subscription costs.
5. **Verdict & Recommendation**: Guidance on who should use it (e.g., beginner, web dev, C++ systems dev, enterprise).
6. **Non-Sponsorship Disclaimer**: Explicit statement of independent evaluation.
