# Google Flow Video Generation Specification Guidelines for IDE Guide (@IDEguide)

## Overview

This document outlines the visual prompt standards, video layout specifications, audio voiceover formatting, and script specifications used for generating video content (YouTube Long-form Videos and Shorts) for **IDE Guide** (@IDEguide) using Google Flow and related AI video generation tools.

---

## 1. Core Production Specifications

### Format & Aspect Ratios
* **YouTube Shorts:** `9:16` vertical video (`1080x1920`), 30/60 fps, 30–60 seconds duration.
* **YouTube Standard Videos:** `16:9` widescreen video (`1920x1080` or `3840x2160`), 60 fps, 3–8 minutes duration.

### Visual & Aesthetic Guidelines
* **Theme:** Dark mode developer environment, sleek modern IDE interfaces, subtle neon accents (cyberpunk subtle blue/cyan/purple glow), high-tech glassmorphism card overlays.
* **Lighting:** Key light soft diffused (5600K cool studio), rim light deep cyan/violet, dark ambient workspace background.
* **Camera Framing & Motion:**
  * Overhead or 3/4 isometric macro shot of keyboard and code terminal.
  * Slow steady push-in / zoom on code editor UI elements (e.g., AI inline auto-complete, split view terminal, extensions sidebar).
  * Smooth pan across side-by-side feature comparison tables.

## 2. Google Flow Visual Prompt Standards

When generating visual clips using Google Flow / Veo / AI Video Generators, use the following standardized prompt template structure:

```
[Subject & Action] + [Camera Angle & Movement] + [Lighting & Style] + [Resolution & Aspect Ratio]
```

### Example Prompt Templates

#### Feature Highlight Scene:
> "Ultra high definition macro close-up of [IDE Name] code editor interface running dark theme with colorful syntax highlighting. Smooth cinematic camera zoom into inline AI suggestion popup. Modern developer desk with ambient cyan backlight, soft bokeh, cinematic 4K, 60fps."

#### Pros vs Cons Split Scene:
> "Split screen visual with high-tech UI graphic elements. Left side glowing green labeled 'Strengths', right side glowing amber labeled 'Limitations'. Minimalist dark cyber aesthetic, fluid animation transitions, high contrast text overlays, 16:9 aspect ratio."

## 3. Video Script Structure & Timing Specs

Every video generated for IDE Guide must follow this structured timeline:

1. **Hook (0:00 - 0:05):** Bold question or key comparison (e.g., "Is [IDE Name] actually better than VS Code in 2026?").
2. **Overview & Features (0:05 - 0:20):** Core engine, key features, performance metrics, supported languages.
3. **Good & Bad / Pros & Cons (0:20 - 0:40):** Honest analysis of strengths (good) and friction points (bad).
4. **Paid vs Free Breakdown (0:40 - 0:50):** Tier details, licensing cost, open-source status, community vs enterprise edition.
5. **Verdict & Audience Recommendation (0:50 - 0:58):** Who should use this editor and who should skip it.
6. **Mandatory Non-Sponsorship Disclaimer (End Screen / Footer Overlay):**
   * *Exact Text:* "Disclaimer: IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation."
