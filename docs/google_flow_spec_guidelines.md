# Google Flow Video Specification Guidelines

This document outlines the standard guidelines and prompt structures for generating AI video specifications using Google Flow, Veo, and other AI video generation tools for the **IDE Guide** YouTube channel ([@IDEguide](https://www.youtube.com/@IDEguide)).

---

## 1. Video Formats & Aspect Ratios

- **YouTube Shorts / TikTok / Reels**: `9:16` vertical aspect ratio (1080x1920). Target duration: 45–60 seconds.
- **YouTube Longform / Standard Video**: `16:9` horizontal aspect ratio (1920x1080). Target duration: 60–180 seconds.

---

## 2. Standard Scene Structure for IDE Reviews

Every video generated for IDE Guide follows a structured multi-scene script:

### Scene 1: Visual Hook & Introduction (0:00 - 0:08)
- **Visual Prompt**: High-energy cinematic shot of a modern dark-themed IDE UI glowing on a ultra-wide curved monitor. Neon ambient lighting (cyan and magenta accents) in a sleek minimalist developer desk setup.
- **Camera Movement**: Fast forward push/dolly zoom toward the editor screen.
- **Voiceover**: Hooking statement comparing or questioning the IDE's standing in modern software engineering.

### Scene 2: Core Overview & Key Capabilities (0:08 - 0:22)
- **Visual Prompt**: Close-up macro visual of code being typed effortlessly in the IDE, highlighting smart autocomplete, AI code generation, or unique window management.
- **Camera Movement**: Slow pan left-to-right across the code syntax highlighting with subtle depth of field blur.
- **Voiceover**: Highlights key features, extension ecosystem, architecture, and language support.

### Scene 3: The Good (Pros & Standout Strengths) (0:22 - 0:36)
- **Visual Prompt**: Vibrant, brightly lit modern workstation showing smooth responsiveness, multi-cursor editing, and fast startup performance visualizer.
- **Camera Movement**: Over-the-shoulder medium shot orbiting slightly around the programmer.
- **Voiceover**: Objectively breaks down what makes this editor superior (speed, AI integration, ecosystem, resource efficiency).

### Scene 4: The Bad (Cons & Limitations) (0:36 - 0:48)
- **Visual Prompt**: Warm amber studio lighting with a slight macro view showing high RAM usage meters, extension conflict warnings, or setup configuration code.
- **Camera Movement**: Subtle tilt down to high-angle shot.
- **Voiceover**: Honest, balanced breakdown of downsides (steep learning curve, memory usage, cost, missing extensions).

### Scene 5: Pricing, License & Verdict (0:48 - 0:55)
- **Visual Prompt**: Clean modern motion-graphics overlay displaying pricing badge (Free / Open Source vs Paid / Subscription) and ideal target user persona.
- **Camera Movement**: Static center lock-on with smooth slide transitions.
- **Voiceover**: Direct recommendation on who should use this IDE and whether it's worth switching.

### Scene 6: Non-Sponsorship Disclaimer & Call-to-Action (0:55 - 1:00)
- **Visual Prompt**: Sleek IDE Guide logo end screen with subscribe bell animation and link prompt to `ideguide.blogspot.com`.
- **Camera Movement**: Smooth fade out to end card.
- **Voiceover / On-screen Text**: Standard non-sponsorship disclaimer and subscription CTA.

---

## 3. Mandatory Non-Sponsorship Disclaimer

All generated scripts and video metadata must contain the exact non-sponsorship disclaimer:

> **Disclaimer**: IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation.

---

## 4. Prompt Engineering Directives for Google Flow

When formulating visual generation prompts:
1. **Subject Clarity**: Explicitly state "A sleek modern IDE UI", "Close-up code editor screen showing Python/TypeScript code", etc.
2. **Lighting**: Specify "Neon cyber-ambient studio backlight", "Soft diffused daylight workspace", or "Moody dark-mode OLED screen glow".
3. **Camera Motion**: Always include motion terms like "Smooth steadycam dolly forward", "Subtle orbit pan", "Cinematic rack focus".
4. **Style**: Use "Photorealistic 8K render, cinematic developer aesthetic, ultra-sharp focus". Avoid cartoon or low-detail prompts unless specified.
