# Google Flow & Visual Video Specification Guidelines for IDE Guide

This document defines the prompt formatting, script conventions, framing standards, camera motion, visual styling, and audio voiceover structures required for generating videos using AI video generation tools (such as Google Flow / Veo / Sora / Runway) for the **IDE Guide** YouTube channel (`https://www.youtube.com/@IDEguide`).

---

## 1. Daily Production Schedule & Video Goals
- **Frequency:** 3 videos per day (Shorts / Vertical Format 9:16 and Widescreen 16:9).
- **Target Audience:** Developers, software engineers, open-source enthusiasts, and students choosing code editors and IDEs.
- **Core Content Pillars:**
  1. Highlighting core features, UI/UX aesthetics, and unique capabilities.
  2. Direct pros/cons and honest evaluation (Free vs. Paid breakdown).
  3. Guidance on ideal developer use cases (e.g., Python web development, C++ embedded, Flutter/Mobile, AI completion).
  4. Clear, non-sponsorship disclosure.

---

## 2. Google Flow Video Prompt Specifications
When generating AI video scenes for IDE showcases, every video scene prompt must follow this structured schema:

```text
[Visual Subject]: A developer workspace / clean dark mode code editor interface featuring [IDE Name].
[Environment & Framing]: Close-up / Medium shot of monitor screen with modern ergonomic mechanical keyboard and ambient lighting.
[Camera Motion]: Slow smooth cinematic pan left-to-right / subtle slow zoom-in on the code completion prompt.
[Lighting & Palette]: Neon accent backlighting (cyan/purple), soft studio key light, crisp high-contrast code highlighting.
[Aspect Ratio]: 9:16 for YouTube Shorts / TikTok, 16:9 for YouTube Longform.
```

### Key Visual Scene Types
1. **The Hero Editor Shot:** Clean, high-resolution rendering of the editor interface with active syntax highlighting and floating AI auto-complete suggestions.
2. **Speed & Efficiency Demonstration:** Split screen or fast dynamic transition showcasing terminal execution, fast search, or debugging tools.
3. **Verdict & Pricing Overlay:** Clean minimalist visual HUD displaying FREE / PAID status, rating badges, and top 3 takeaways.

## 3. Audio & Voiceover Script Format
Each video script generated by our agentic tools includes time-stamped narration script lines:

```text
[00:00 - 00:05] Hook: "Looking for the ultimate code editor for Python and AI development? Meet [IDE Name]!"
[00:05 - 00:15] Showcase: "Here is what makes [IDE Name] stand out: fast code indexing, built-in intelligent inline completion, and seamless Git integration."
[00:15 - 00:25] Pros & Cons: "PROS: Blazing speed, minimal memory usage. CONS: Limited extension ecosystem compared to VS Code."
[00:25 - 00:35] Pricing & Recommendation: "PRICING: 100% Free and Open Source. Is it right for you? If you prioritize lightweight performance, absolutely!"
[00:35 - 00:40] Disclaimer & Call to Action: "Disclaimer: IDE Guide is independent and not sponsored. Subscribe to @IDEguide for daily editor breakdowns!"
```

## 4. Standard Disclaimer
All video specifications and descriptions **must** include the mandatory non-sponsorship statement:

> **Disclaimer:** IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation.
