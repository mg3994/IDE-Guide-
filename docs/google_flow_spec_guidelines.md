# Google Flow Video Prompt & Script Specifications

This document outlines the visual prompting guidelines, camera angles, lighting setup, script structure, and JSON specification format used for generating YouTube videos and Shorts for the **IDE Guide** channel ([@IDEguide](https://www.youtube.com/@IDEguide)).

## 1. Overview & Content Goals

IDE Guide produces 3 daily videos/shorts evaluating software development environments, code editors, and IDEs.
Each video specification adheres to the following principles:
- **Objective Evaluation**: Highlights key pros, cons, target use cases, and pricing structure (Free vs Paid).
- **Visual Excellence**: Provides detailed AI video prompts (for Google Flow, Google Veo, Runway Gen-2/3, Sora) with explicit camera motion, lighting, aesthetic framing, and UI close-ups.
- **Independent Disclaimer**: Every script and video package includes our mandatory non-sponsorship disclaimer:
  > "Disclaimer: IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation."

## 2. Visual Prompting Specifications for Google Flow

### Aspect Ratios & Formats
- **YouTube Main Video (16:9)**: Resolution `1920x1080` or `3840x2160`. Frame rate `30fps` or `60fps`. Cinematic developer setup with split-screen code editing visuals.
- **YouTube Shorts (9:16)**: Resolution `1080x1920`. Vertical orientation with centered high-contrast typography, close-up syntax highlighting, and fast-paced visual transitions.

### Camera Motions & Framing Rules
1. **Hook Scene (0-5s)**: Dynamic macro push-in camera shot of glowing mechanical keyboard and high-resolution screen displaying code in the featured IDE. Dark ambient room with neon accent lighting.
2. **Overview Scene (5-15s)**: Smooth slow pan across the IDE user interface showcasing sidebar navigation, file tree, and primary code editor window. Clean, minimalist aesthetic.
3. **Features & Pros (15-35s)**: High-speed rack focus between developer hands typing and code autocomplete/AI assistant popup on screen. Crisp 4K cinematic lighting.
4. **Drawbacks & Cons (35-45s)**: Cool-toned low-key lighting shot of system monitor showing memory usage graphs or configuration file complexity, subtitled with clear warnings.
5. **Pricing & Verdict (45-60s)**: High-contrast split visual showing Free vs Pro badge, followed by an elegant slide-in recommendation score card and channel subscribe CTA.

### Color Palette & Lighting
- **Key Lighting**: Soft 5600K daylight key light on developer desk.
- **Accent Lighting**: Cyberpunk cyan (#00f2fe) and magenta (#4facfe) LED backlight behind monitors for technical depth.
- **UI Focus**: Clean dark-mode editor theme (Monokai, One Dark, Catppuccin, or Dracula) for visual clarity in video outputs.

## 3. Google Flow JSON Specification Structure

Each video package generated by IDE Guide tools produces a structured JSON file formatted for Google Flow video generation workflows:

```json
{
  "title": "IDE Guide Review - [IDE Name]",
  "format": "long_form | shorts",
  "aspect_ratio": "16:9",
  "ide_name": "[IDE Name]",
  "disclaimer": "Disclaimer: IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation.",
  "scenes": [
    {
      "scene_number": 1,
      "duration_seconds": 5,
      "narration_script": "Voiceover audio text...",
      "visual_prompt": "Cinematic close-up macro shot of [IDE Name] user interface...",
      "camera_angle": "Macro close-up, 45 degree tilt, slow push-in",
      "lighting": "Dark ambient neon blue backlight, 5600K soft key light"
    }
  ],
  "pricing": {
    "tier": "Free / Open Source | Freemium | Paid",
    "details": "Pricing breakdown details..."
  },
  "verdict": "Final summary recommendation..."
}
```
