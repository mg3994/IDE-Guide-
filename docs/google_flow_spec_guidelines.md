# Google Flow Video Generation Specification Guidelines for IDE Guide

This document defines the prompt engineering standards, visual aesthetics, lighting configurations, camera motions, and voiceover scripting guidelines for generating high-attraction YouTube videos and Shorts for **IDE Guide** (`https://www.youtube.com/@IDEguide`).

---

## 🎯 1. Channel Objectives & Standards

- **Channel:** IDE Guide ([@IDEguide](https://www.youtube.com/@IDEguide))
- **Blog Partner:** IDE Guide Blogger ([ideguide.blogspot.com](https://ideguide.blogspot.com/))
- **Daily Target:** 3 Shorts (60s) and 3 Long-Form Video Specs (3-5 mins) generated alongside 3 AMP HTML blog posts.
- **Mandatory Non-Sponsorship Statement:**
  > *"Disclaimer: IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation."*

---

## 🎥 2. Visual Prompt Engineering for Google Flow & AI Generators

When generating video clips using Google Flow, Runway Gen-2, or Sora, every scene prompt must incorporate four critical parameters:

1. **Environment & Workspace:** High-end modern developer workspace, dark mode IDE UI, mechanical keyboards, dual 4K curved monitors, ambient RGB backlighting.
2. **Camera Motion:** Smooth panning, slow macro zoom, shallow depth of field (f/1.8), cinematic dolly-in toward active code lines.
3. **Lighting & Color Palette:** Cyberpunk neon blue (#6366f1) and dark slate (#0f172a), high contrast code highlighting, soft rim lighting.
4. **Overlay Design:** Sleek translucent glassmorphism cards with bold typography (Inter/SF Pro) displaying Pros, Cons, and Pricing badges.

## 📱 3. YouTube Shorts Specifications (9:16 Vertical)

- **Aspect Ratio:** 9:16 (1080x1920)
- **Duration:** 60 Seconds
- **Structure:**
  - **Hook (0-5s):** Fast zoom onto editor UI + high energy question ("Is [IDE] actually worth using?").
  - **The Good (5-25s):** Rapid feature callouts with green checkmarks and code animation.
  - **The Bad (25-45s):** Feature limitations and warning highlights.
  - **Verdict & Pricing (45-60s):** Free vs Paid badge + call to subscribe to `@IDEguide` and visit `ideguide.blogspot.com`.

---

## 🖥️ 4. YouTube Long-Form Video Specifications (16:9 Widescreen)

- **Aspect Ratio:** 16:9 (3840x2160)
- **Duration:** 3 - 5 Minutes
- **Structure:**
  1. Introduction & Editorial Non-Sponsorship Disclaimer
  2. Core Architecture & Feature Overview
  3. Objective Pros & Strengths
  4. Drawbacks, Resource Footprint, & Cons
  5. Pricing Breakdown (Free Community vs Paid Enterprise)
  6. Final Verdict & Target Developer Persona
