# Google Flow Video Generation Specification Guidelines

This document provides visual prompt standards, video script structure, framing guidelines, and camera directives for creating high-engagement videos and YouTube Shorts for [@IDEguide](https://www.youtube.com/@IDEguide).

## 1. Video Types & Targets

1. **YouTube Shorts (Vertical 9:16)**: 30-60 second fast-paced reviews/tips highlighting key IDE features, pros/cons, and pricing.
2. **YouTube Long-form Videos (Horizontal 16:9)**: Detailed deep-dives (3-5 mins script spec) covering installation, configuration, key pros/cons, and IDE comparisons.

## 2. Google Flow & Visual Prompt Specifications

When generating visual sequences for video production tools like Google Flow / Veo / Runway, use structured visual prompts including:

- **Style / Aesthetic**: Modern tech aesthetic, sleek minimal studio, high-tech dark mode workstation, subtle glowing neon accents, clean developer UI overlays.
- **Framing & Camera Angles**:
  - *Close-up*: Developer hands typing on mechanical keyboard, crisp screen macros showing IDE UI details.
  - *Medium Shot*: Presenter/avatar at clean standing desk with Ultrawide dual monitor setup.
  - *Over-the-shoulder*: Code editor side-by-side comparison view.
- **Lighting & Color Palette**: Cool blue and violet dark mode ambiance, sharp key lighting on subject, soft ambient backlighting.
- **Motion & Pace**: Dynamic smooth camera panning, snappy zoom cuts during key feature highlights.

## 3. Video Script Structure

Every daily video specification includes:

1. **Hook (0:00 - 0:05)**: Attention-grabbing question or statement (e.g., "Is Cursor actually replacing VS Code in 2026?").
2. **Overview (0:05 - 0:20)**: Quick overview of the editor, main features, and license model (Free / Paid / Freemium).
3. **The Good (Pros)**: Highlighting top 2-3 features that developers love.
4. **The Bad (Cons)**: Objective callouts of downsides, resource usage, or pricing tiers.
5. **Verdict & Recommendation**: Final verdict on who should use it.
6. **Non-Sponsorship Disclaimer**: Explicit voiceover/caption:
   > "IDE Guide is independent and not sponsored by any IDE vendor. All reviews are 100% unbiased."
