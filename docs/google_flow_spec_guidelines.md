# Google Flow Video Generation Specification Guidelines

## Overview

This document specifies the prompt engineering standards, visual aesthetics, camera framing, lighting, motion cues, and script formats required for generating video content for **IDE Guide** YouTube channel ([@IDEguide](https://www.youtube.com/@IDEguide)) and Blogger site ([ideguide.blogspot.com](https://ideguide.blogspot.com/)).

The specifications defined here are designed for AI video generation engines like Google Flow, Veo, and Sora to produce engaging visual videos and shorts showcasing code editors and IDEs.

---

## 1. Video Formats & Technical Specifications

| Format | Aspect Ratio | Resolution | Duration | Target Platform |
| :--- | :--- | :--- | :--- | :--- |
| **YouTube Short** | 9:16 (Vertical) | 1080 × 1920 | 30 – 60 seconds | YouTube Shorts / Reels |
| **YouTube Main Video** | 16:9 (Widescreen) | 1920 × 1080 | 2 – 5 minutes | YouTube Main Channel |

---

## 2. Visual Style & Cinematic Guidelines

### Lighting & Atmosphere
- **Primary Style:** High-contrast developer studio aesthetic in dark mode.
- **Key Light:** Soft ambient backlight casting cyan and magenta neon rim lighting on high-end developer workstations.
- **Screen Display:** Sharp, ultra-crisp IDE code editing interface with vibrant syntax highlighting (Monokai, One Dark, or Dracula themes).
- **Environment:** Clean modern workspace with mechanical keyboard keycaps, sleek dual monitor setup, subtle bokeh background.

### Camera Angles & Framing
- **Close-up Shots (CU):** Macro lens focus on mechanical keyboard typing or glowing screen cursor movement with soft depth of field.
- **Medium Shots (MS):** Over-the-shoulder view of a developer coding, demonstrating IDE features, AI autocompletion, or extension panels.
- **Wide Shots (WS):** Dynamic camera panning across the sleek developer desk setup with glowing RGB accents.
- **Camera Movements:** Smooth slider pans, slow push-ins during key feature highlights, dynamic speed-ramped transitions between pro/con comparisons.

---

## 3. Script Structure & Voiceover Guidelines

Every video script must strictly follow this narrative structure:

1. **Hook (0:00 - 0:05):** Bold statement or question highlighting the IDE's primary differentiator (e.g., "Is Cursor actually replacing VS Code in 2026?").
2. **Overview & Differentiator (0:05 - 0:15):** Core introduction, who built it, and key engine/architecture details.
3. **The Good (Pros) (0:15 - 0:30):** Top 2-3 killer features (e.g., AI autocomplete, multi-cursor speed, extension ecosystem).
4. **The Bad (Cons) (0:30 - 0:42):** 1-2 honest drawbacks (e.g., resource usage, telemetry, subscription cost).
5. **Verdict & Pricing (0:42 - 0:52):** Free vs Paid tier breakdown and clear recommendation on who should use it.
6. **CTA & Mandatory Disclaimer (0:52 - 1:00):** Channel subscribe CTA and non-sponsorship disclosure.

All visual scripts, descriptions, and accompanying metadata MUST include the exact non-sponsorship disclaimer text:

> **Disclaimer:** IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation.

## 5. Google Flow Visual Spec Schema

Each video spec generated by IDE Guide scripts outputs a structured package containing:

- `title`: Video title optimized for YouTube search.
- `target_format`: `YouTube Short (9:16)` or `YouTube Video (16:9)`.
- `ide_name`: Name of the IDE evaluated.
- `pricing`: Free, Paid, Freemium, or Open Source pricing details.
- `voiceover_script`: Full spoken narration script.
- `scenes`: Array of visual scenes, each containing:
  - `scene_number`: Sequential integer.
  - `timestamp`: Time interval (e.g., `00:00 - 00:05`).
  - `visual_prompt`: Detailed prompt string formatted for Google Flow video generation engine.
  - `camera_framing`: Camera angle and movement cue.
  - `lighting`: Lighting setup description.
  - `narration`: Matching spoken audio snippet.
- `disclaimer`: Exact non-sponsorship text.
