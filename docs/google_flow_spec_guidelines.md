# Google Flow & AI Video Production Specifications

Guidelines and prompt engineering standards for generating high-retention video content and YouTube Shorts for **IDE Guide** (`https://www.youtube.com/@IDEguide`) using **Google Flow** and generative video AI tools.

---

## 1. Video Formats & Target Ratios

| Content Type | Aspect Ratio | Duration | Target Platform | Primary Focus |
| :--- | :--- | :--- | :--- | :--- |
| **Full Video Feature** | 16:9 (`1920x1080`) | 3 to 8 minutes | YouTube Standard | Deep dive, pros & cons, setup walkthrough, comparison |
| **YouTube Shorts / Reel**| 9:16 (`1080x1920`) | 45 to 60 seconds | YouTube Shorts / TikTok | High-impact hook, 3 rapid pros/cons, pricing verdict |

---

## 2. Google Flow Prompting Architecture

To produce visually compelling cinematic video generations using Google Flow or similar neural video synthesizers, prompts must follow a strict multi-layered structure:

```
[Camera Shot & Motion] + [Subject & Action] + [Lighting & Atmosphere] + [Visual Aesthetic & Color Grade] + [Technical Fidelity]
```

### Prompt Attributes
1. **Camera Shot & Motion**:
   - `Smooth cinematic slow dolly-in toward an ultra-sleek developer workstation...`
   - `Macro close-up tracking shot moving across an illuminated mechanical keyboard and code editor monitor...`
   - `Vertical Dutch-tilt panning down a vertical high-resolution display running dark mode code...`

2. **Subject & Visual Action**:
   - `Developer typing blazing-fast syntax in [IDE Name] dark mode theme, code completion popups glowing subtly in neon cyan.`
   - `Split screen visual comparison showing memory usage gauge dropping rapidly.`

3. **Lighting & Atmosphere**:
   - `Moody ambient cyberpunk blue and amber neon rim lighting, subtle volumetric haze, reflections on matte black desk.`

4. **Technical Quality & Fidelity**:
   - `8k resolution, photorealistic, cinematic 60fps, clean render, sharp focus, no artifacts.`

---

## 3. High-Retention Narrative Script Structure (3 Videos / Day)

Each generated video script follows the proven YouTube retention arc:

```
[00:00 - 00:05] THE HOOK (Problem statement or bold contrarian claim)
[00:05 - 00:25] THE GOOD (Top 2-3 standout features & speed demonstration)
[00:25 - 00:40] THE BAD (Critical pain points, memory usage, pricing catches)
[00:40 - 00:52] THE VERDICT (Free vs. Paid clarity, who should use it)
[00:52 - 00:60] CALL TO ACTION & MANDATORY DISCLAIMER
```

## 4. Visual Prompt Template for Shorts (9:16)

```text
Scene 1 (Hook - 0-5s):
Visual Prompt: Extreme close-up vertical shot 9:16, a developer staring intensely at a glowing 4K screen with code reflecting in eyeglasses, dramatic red-to-blue neon studio lighting, cinematic 4k.
Voiceover: "Stop using your current code editor until you see this."

Scene 2 (The Good - 5-25s):
Visual Prompt: Vertical macro shot 9:16 panning down an ultra-responsive code buffer in [IDE Name], instant multi-cursor refactoring, smooth 60fps UI motion, dark theme with vibrant pastel highlights.
Voiceover: "Here is why developers are switching: [Key Strengths]."

Scene 3 (The Bad - 25-40s):
Visual Prompt: Vertical shot 9:16 showing split screen memory consumption graphs surging, red warning indicator accents, cinematic lighting.
Voiceover: "But before you migrate, watch out for the downside: [Weaknesses]."

Scene 4 (Pricing & Recommendation - 40-60s):
Visual Prompt: Sleek minimalist graphic on modern display showing Free vs Pro price badges, followed by IDE logo banner, clean studio aesthetic.
Voiceover: "[Pricing breakdown]. We are 100% independent and unsponsored—subscribe to IDE Guide for honest developer reviews."
```

All scripts, on-screen text overlays, and video descriptions must declare:
> "Disclaimer: IDE Guide is an independent technical publication. This video is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned. All reviews and assessments are based strictly on objective developer evaluation."
