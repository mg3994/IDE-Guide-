# Google Flow Video Prompt & Production Guidelines

Target Channel: [IDE Guide YouTube](https://www.youtube.@IDEguide)

## 1. Overview
IDE Guide produces 3 short and engaging video content pieces daily (ranging from 60s Shorts to 3-minute video overviews) showcasing code editors, IDEs, extensions, and AI developer tools.
These specifications are crafted for AI video generation engines like **Google Flow** / Veo and video generation workflows.

## 2. Standard Visual & Prompt Parameters

### A. Camera & Visual Framing
- **Framing**: Close-up on ultra-clean IDE visual interface, split-screen code comparisons, and high-definition macro shots of developer setups.
- **Lighting**: Soft dark-mode glow, vibrant blue/purple accent neon lighting, studio quality, cinematic 4K look.
- **Motion**: Smooth cinematic panning across code blocks, subtle zooming on benchmark stats, dynamic text overlays.

### B. Aspect Ratio & Duration
- **YouTube Shorts (9:16)**: Vertical format, 60 seconds duration, quick-paced transitions every 3-5 seconds.
- **Standard Video (16:9)**: Horizontal format, 180 seconds duration, structured deep-dive format.

### C. Audio & Voice Specification
- **Voiceover Style**: Energetic, articulate, authoritative developer voice (neutral accent, crisp voiceover prompt).
- **Background Audio**: Minimalist lo-fi synthwave ambient soundtrack.

## 3. Required Video Script & Spec Sections
Each generated Google Flow specification document (`video_spec_*.json` / `video_script_*.md`) must contain:
1. **Metadata**: Title, Target Platform, Visual Style, Duration, Topic ID.
2. **Scene-by-Scene Breakdown**:
   - `Scene ID` & `Timestamp`
   - `Visual Flow Prompt` (Google Flow visual prompt description)
   - `Camera Motion` & `Lighting`
   - `Voiceover Script` (exact narration words)
   - `On-Screen Text Callout`
3. **IDE Analysis Breakdown**:
   - Highlighting Key Features & Killer Functions
   - Pros vs Cons
   - Free vs Paid Pricing & Licensing Details
   - Recommendation & Verdict
4. **Mandatory Non-Sponsorship Disclaimer** (spoken or on-screen overlay):
   > "Disclaimer: IDE Guide is an independent technical publication. Content is not sponsored or endorsed by any vendor."
