# Google Flow Video & Shorts Specifications (IDE Guide)

This document provides specifications for generating video creation prompts, scripts, visual storyboards, and camera directions for Google Flow and AI video creation platforms for YouTube (`https://www.youtube.com/@IDEguide`).

## 1. Daily Video Strategy & Output

IDE Guide publishes **3 videos daily** (Long-form reviews and Shorts/Reels):
1. **Short/Reel 1**: Quick 60-second IDE Verdict / Comparison (High energy, punchy hook).
2. **Short/Reel 2**: Pros & Cons Breakdown ("The Good & The Bad of [IDE]").
3. **Video 3**: Complete Hands-On Guide & Best Use Case Recommendations (Free vs. Paid, Feature Deep Dive).

## 2. Google Flow Prompt Specifications

Each generated video specification JSON/Markdown file must include detailed fields for AI video tools:

### A. Video Metadata
- **Title**: High CTR title with target IDE keyword.
- **Format**: `Short` (9:16 vertical) or `Video` (16:9 horizontal).
- **Target Duration**: 60s (Shorts) or 3-5 mins (Video).

### B. Visual & Camera Directions
- **Framing**: `Vertical 9:16` for Shorts, `Horizontal 16:9` for standard video.
- **Visual Style**: Modern dark tech theme, high contrast code syntax highlighting, crisp IDE UI closeups, holographic 3D graphics overlay.
- **Lighting**: Cyberpunk studio lighting (Deep indigo background with subtle neon blue and teal rim lighting).
- **Camera Angles**:
  - *Scene 1*: Dynamic zoom-in on IDE logo and key editor UI.
  - *Scene 2*: Split-screen visual comparison (Code performance, extension market, memory usage graph).
  - *Scene 3*: Macro focus on AI coding assistant tab / code completion in action.

### C. Voiceover Script & Audio Cues
- **Hook (0-5s)**: Immediate problem-solving statement (e.g., "Stop picking the wrong code editor in 2026! Here is the honest truth about [IDE]...").
- **Core Breakdown**: Concise overview of pricing (Free vs Paid), top 3 pros, top 2 cons.
- **Recommendation**: Exact recommendation for who should use it.
- **Background Music / Audio**: Upbeat energetic synthwave or sleek lo-fi tech beats.

### D. Standard Non-Sponsorship Disclaimer
- **Audio & Visual Disclaimer Overlay**:
  > "Disclaimer: IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation."
