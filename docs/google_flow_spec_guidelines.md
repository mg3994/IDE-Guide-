# Google Flow Video Prompt & Script Specifications

These guidelines define the visual prompt generation standards and video script structures for YouTube content on [@IDEguide](https://www.youtube.com/@IDEguide).

## 1. Video Formats & Orientations

### Long-Form Videos (16:9 Aspect Ratio)
- **Target Duration:** 3 to 8 minutes.
- **Goal:** In-depth IDE showcase covering architecture, core strengths, weaknesses, pricing tiers, and ideal developer personas.
- **Visual Style:** Clean developer workspace, sleek IDE UI closeups, high-contrast code themes, cinematic studio lighting.

### YouTube Shorts (9:16 Vertical Aspect Ratio)
- **Target Duration:** 30 to 60 seconds.
- **Goal:** Rapid-fire feature highlights, "Vs" quick comparisons, or key takeaways.
- **Visual Style:** Fast-paced cuts, bold text overlays, dynamic camera motions, vertical studio view.

## 2. Google Flow Prompt Formatting Rules

When writing visual generation prompts for Google Flow / AI video generators, provide key parameters per scene:
1. **Framing & Camera:** Close-up on editor screen, over-the-shoulder programmer view, smooth dolly zoom, tracking shot.
2. **Lighting & Mood:** Modern tech studio ambient lighting, dark theme glowing neon accents, 4k ultra-detailed photorealistic render.
3. **Action & Motion:** Hands typing on mechanical keyboard, code scrolling rapidly, UI popups highlighting AI completion.

## 3. Mandatory Non-Sponsorship Statement in Audio Script
Every video script must include spoken narrative or screen overlay text stating:
> *"IDE Guide is an independent technical publication. This content is not sponsored or affiliated with any software vendor."*
