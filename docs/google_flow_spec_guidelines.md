# Google Flow Video Prompt & Spec Guidelines - IDE Guide

This document establishes standard operating specifications for generating visual video prompts, scripts, and production blueprints for the **IDE Guide** YouTube channel ([@IDEguide](https://www.youtube.@IDEguide)) and companion Blogger site ([ideguide.blogspot.com](https://ideguide.blogspot.com/)).

---

## 1. Daily Production Cadence & Channel Objective

- **Daily Cadence:** 3 AMP HTML Blog Posts + 3 Video / Short Generation Specs generated every 24 hours.
- **Mission:** Provide objective, high-value visual reviews of modern IDEs, code editors, extensions, and developer tooling (VS Code, Cursor, Neovim, JetBrains suite, Zed, Helix, Fleet, etc.).
- **Monetization & Transparency:** Purely independent. Every video script and blog post MUST include the mandatory non-sponsorship disclaimer.

---

## 2. Visual Prompt Engineering & Framing Standards

When crafting prompts for Google Flow and generative video AI tools, use structured prompt parameters to achieve consistent technical aesthetics:

### A. Framing & Aspect Ratios
- **Main YouTube Video (16:9 4K):** Medium close-up of developer workspace, high-definition screen captures of IDE UI with macro close-ups on syntax highlighting and auto-complete dropdowns.
- **YouTube Shorts / Reels (9:16 Vertical):** Vertical center-framed UI callouts with dynamic zooming on key editor features (e.g., AI inline edit, speed benchmarks).

### B. Lighting & Color Palette
- **Cyberpunk Dark Mode:** Deep charcoal `#1e1e2e` background with vibrant syntax glow (neon cyan `#89b4fa`, vivid purple `#cba6f7`, bright green `#a6e3a1`).
- **Studio Tech Glow:** Soft ambient backlight behind a sleek minimalist desk setup with high-contrast screen illumination.

### C. Camera Movement
- **Push-in Zoom:** Slow 1.2x camera push towards code completion prompts or key shortcuts.
- **Lateral Pan:** Smooth horizontal tracking shot across code editor tab bars and sidebars.
- **Split-Screen Comparison:** Side-by-side dynamic split screen showing performance benchmarks (RAM usage, startup latency, extension load time).

---

## 3. Video Script Breakdown Template

Each video specification follows a strict 6-part structure designed to maximize audience engagement and retention:

1. **Hook (0:00 - 0:05):** Bold statement or question regarding developer productivity or editor performance.
2. **Overview & Pricing (0:05 - 0:30):** Introduction of the IDE, developer/company behind it, and explicit pricing model (Free / Freemium / Open Source / Commercial License).
3. **Pros & Killer Features (0:30 - 1:30):** Deep dive into standout capabilities (e.g., AI assistance, multi-cursor, tree-sitter syntax parser, LSP integration).
4. **Cons & Limitations (1:30 - 2:30):** Honest critique of resource consumption, configuration complexity, ecosystem maturity, or missing features.
5. **Verdict & Recommendation (2:30 - 3:00):** Clear recommendation on target audience (e.g., "Best for Rust developers", "Ideal for minimalists", "Worth upgrading to paid tier").
6. **Mandatory Disclaimer:** Spoken audio overlay and visual text banner.
