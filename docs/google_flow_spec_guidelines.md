# Google Flow Video Prompt & Spec Guidelines for IDE Guide

These guidelines define the specifications for generating prompts and video scripts for YouTube videos and shorts for [@IDEguide YouTube Channel](https://www.youtube.com/@IDEguide).

## Structure of Video Generation Specs

Each generated video specification file must include detailed components tailored for AI video creation engines (such as Google Flow / Veo):

1. **Metadata**:
   - **Title**: Catchy, search-optimized title including the IDE name.
   - **Target Duration**: 60 seconds (Shorts) or 3-5 minutes (Full Video).
   - **Format / Aspect Ratio**: `9:16` for Shorts/Reels, `16:9` for Full Video.

2. **Google Flow Video Prompts (Per Scene)**:
   - **Scene Number & Timestamp**.
   - **Visual Prompt**: Highly detailed camera, lighting, environment, and subject instructions for AI video synthesis.
   - **Framing & Camera Movement**: e.g. "Macro close-up on dark mode code editor, smooth push-in shot, high contrast neon accent lighting".
   - **On-Screen Text**: Clean typography overlays.
   - **Voiceover Script**: Clear, energetic narrative.
   - **Audio / BGM Prompt**: Background music style (e.g. "Lo-fi synthwave ambient beat with subtle mechanical keyboard typing sounds").

3. **Required Content Coverage**:
   - **Overview**: What the IDE/editor is designed for.
   - **Pricing**: Clear indication of whether it is Free, Paid, Subscription, or Freemium.
   - **Pros / The Good**: Standout features, extensions, performance, AI integrations.
   - **Cons / The Bad**: Memory usage, learning curve, license restrictions, startup speed.
   - **Verdict**: Clear recommendation on who should use it.

4. **Mandatory Non-Sponsorship Disclaimer**:
   - Must contain the spoken and on-screen disclaimer:
   > "Disclaimer: IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation."
