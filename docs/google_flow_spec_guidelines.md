# Google Flow Video Spec Guidelines for IDE Guide

This document defines the prompt structure, visual framing, camera direction, lighting, script formatting, and video generation specifications for **IDE Guide** YouTube content ([@IDEguide](https://www.youtube.com/@IDEguide)).

## 1. Overview & Objectives

IDE Guide creates daily technical video breakdowns, reviews, and comparative analysis of IDEs and code editors for YouTube (Long-form 16:9 videos and YouTube Shorts 9:16).

To leverage AI video tools such as **Google Flow** effectively, each video specification provides detailed visual generation prompts, camera instructions, lighting parameters, script narration with timestamps, and visual cues.

## 2. Google Flow Video Spec Structure

Every Google Flow video specification output must include:

1. **Metadata**:
   - Title & Target Platform (YouTube Video 16:9 / Shorts 9:16)
   - Duration & Aspect Ratio
   - Core Topic (IDE / Code Editor being evaluated)
2. **Visual & Aesthetic Style**:
   - **Lighting**: Studio ambient glow, dark mode code editor contrast, soft key light on hardware/developer desk, subtle RGB accent lighting (cyan/magenta).
   - **Framing**: Macro close-up on code editor interface, medium over-the-shoulder shot of a developer typing, split-screen side-by-side IDE comparison.
   - **Color Palette**: Dark slate blue `#1e1e2e`, neon teal accents `#89dceb`, crisp white text `#cdd6f4`.
3. **Timeline & Script Prompts (Google Flow Sequence)**:
   - **Timestamp**: Breakdown in 5 to 15-second scenes.
   - **Voiceover Narration**: Clear, engaging, objective technical breakdown.
   - **Visual Cue / Flow Prompt**: Detailed prompt string optimized for Google Flow video generation model.
   - **Good & Bad Assessment**: Visual highlight of pros, cons, performance speed, memory footprint.
   - **Pricing Breakdown**: Paid vs Free vs Open Source visual badges.
4. **Mandatory Non-Sponsorship Disclaimer**:
   - Included in video narration script summary and description metadata.

## 3. Standard Google Flow Prompt Guidelines

When framing prompts for Google Flow video generation:
- Specify camera motion: `Slow zoom-in on code editor cursor`, `Dynamic pan across dark theme IDE UI`, `Cinematic over-the-shoulder shot`.
- Specify lighting and render fidelity: `Hyper-realistic 4K studio lighting, soft depth of field background, high contrast IDE screen display`.
- Keep visual cues clear and synchronized with voiceover timestamps.

## 4. Mandatory Non-Sponsorship Disclaimer

All video specifications and descriptions must include the exact text:

`Disclaimer: IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation.`
