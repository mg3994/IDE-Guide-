# Google Flow Video & Shorts Prompt Specifications (IDE Guide)

This document provides visual guidelines, prompt templates, and structural specifications for generating video assets using AI video tools (such as Google Flow / Veo / Imagen Video) for [IDE Guide YouTube Channel](https://www.youtube.com/@IDEguide).

---

## 1. Video Specifications & Technical Standards

- **Output Formats:**
  - **YouTube Short / Vertical:** 1080x1920 (9:16 aspect ratio), 30-60 seconds duration.
  - **YouTube Video / Horizontal:** 1920x1080 (16:9 aspect ratio), 2-5 minutes duration.
- **Lighting & Aesthetics:**
  - Modern tech workstation aesthetic: Dark mode interfaces, subtle neon accent lighting (cyan #00F0FF, violet #8A2BE2, emerald green #00FF88).
  - High contrast, crisp code snippet rendering, cinematic macro camera close-ups.
- **Framing & Motion:**
  - Smooth 4K cinematic camera pans across screen displays.
  - Slow-motion keyboard keystrokes with RGB backlighting.
  - Split-screen visual comparisons for "Good vs Bad" or "Paid vs Free".

---

## 2. Structured Prompt Generation Schema

Every video specification generated by IDE Guide includes detailed prompts for visual generators and voiceover scripts:

### Scene Breakdown Structure
Each video spec file (JSON or Markdown) contains a minimum of 4 distinct scenes:
1. **Scene 1: Hook / Introduction**
   - **Visual Prompt:** Cinematic camera dolly shot of a developer setup with dual monitors showing code editors. Neon glow, modern aesthetic, 8k resolution.
   - **Voiceover Script:** Quick engaging hook posing the comparison or key question.
2. **Scene 2: Core Highlights & Pros ("The Good")**
   - **Visual Prompt:** Macro lens close-up of fast AI code completion, sleek UI layout, real-time extension execution.
   - **Voiceover Script:** Concise walkthrough of key benefits, performance metrics, and top features.
3. **Scene 3: Drawbacks & Limitations ("The Bad")**
   - **Visual Prompt:** High-contrast camera angle showing high RAM usage warning or subscription lock modal on screen.
   - **Voiceover Script:** Honest discussion of weaknesses, resource consumption, or paywalls.
4. **Scene 4: Pricing Model & Verdict**
   - **Visual Prompt:** Split screen graphic displaying pricing tier badges (FREE vs PAID) transitioning to channel call-to-action graphic.
   - **Voiceover Script:** Pricing breakdown, final recommendation on who should use it, subscriber CTA, and mandatory disclaimer.

## 3. Mandatory Non-Sponsorship Disclaimer

Every video script must conclude with the audio/visual disclaimer:
> "Disclaimer: IDE Guide is an independent technical publication. Content is not sponsored, endorsed, or affiliated with any software vendor. Reviews are based on objective developer evaluation."
