# Google Flow Video & Shorts Generation Guidelines

This guide defines specifications for generating visual video scripts and prompts tailored for Google Flow (and related AI video generation tools) for the YouTube Channel [`@IDEguide`](https://www.youtube.com/@IDEguide).

---

## 1. Daily Content Format & Goals

For `@IDEguide`, 3 video packages/specs are generated daily:
* **Shorts / Reels (15-60 sec)**: High-energy, fast-paced overview focusing on key highlights, pricing, and top pros/cons.
* **In-Depth Videos (3-8 min)**: Complete walkthrough, feature breakdown, developer benchmark performance, and paid vs free comparison.

---

## 2. Google Flow Prompt Specifications

Every video generation spec file includes structured Google Flow prompts formatted as JSON and Markdown.

### Scene Prompt Components

Each scene specification must define:

1. **Visual Scene Prompt (Google Flow AI Input)**:
   - High-fidelity prompt describing visual assets, camera movement, lighting, and environment.
   - Example: `"Ultra clean dark mode IDE interface displaying Python code with neon syntax highlighting. Smooth 4K slow dolly shot forward into glowing auto-complete AI suggestions box. Cinematic studio lighting, subtle motion blur."`

2. **Framing & Aspect Ratio**:
   - Vertical (`9:16`) for YouTube Shorts (1080x1920).
   - Horizontal (`16:9`) for Standard YouTube Videos (1920x1080).

3. **Camera Movement & Lighting**:
   - Dynamic motion (e.g. `Pan Right`, `Zoom In`, `Macro Close-Up`, `Over-The-Shoulder Developer View`).
   - High-contrast developer aesthetic: Dark mode editor, RGB mechanical keyboard backlight, ambient blue/purple studio glow.

4. **Audio Narration Script**:
   - Natural spoken text for text-to-speech or voiceover recording.

5. **On-Screen Text Overlays**:
   - Clear, high-contrast captions highlighting key takeaways (e.g., "FREE & Open Source", "AI Codebase Search", "Pros vs Cons").

---

## 3. Mandatory Non-Sponsorship Disclaimer

Every video script / spec must include the mandatory non-sponsorship disclosure in the audio script and end screen:

> "Disclaimer: IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation."

---

## 4. Output File Structure

Video specs generated by daily automation or agentic CLI skills are saved alongside AMP blog posts under `content/YYYY-MM-DD/` with file naming pattern:
- `video_spec_<ide_id>.json`
- `video_script_<ide_id>.md`
