# Google Flow Video Prompt & Production Guidelines for @IDEguide

This document specifies the standard specs, prompt structures, camera controls, lighting setups, audio parameters, and visual style guidelines for generating high-converting YouTube Shorts and Videos using AI video tools (such as Google Flow / Veo / Sora / Runway) for the **IDE Guide** YouTube channel (`https://www.youtube.com/@IDEguide`).

---

## 1. Overview & Strategy

**IDE Guide** publishes 3 videos every day:
1. **Vertical Short 1 (9:16, 30-60s)**: High-energy IDE quick review, killer feature spotlight, or speed comparison.
2. **Vertical Short 2 (9:16, 30-60s)**: Pros vs Cons / Free vs Paid showdown for a specific developer workflow.
3. **Horizontal Video (16:9, 3-5m / 60s preview)**: Deep-dive IDE showcase, extension ecosystem, and setup guide.

All videos follow strict visual flow standards to maintain brand identity, high audience retention, and clear technical value.

---

## 2. Visual Prompt Framework for Google Flow

When writing video prompts for Google Flow / AI generation tools, every prompt MUST include 5 core components:

```
[Subject/Environment] + [Action/Motion] + [Lighting/Mood] + [Camera Angle & Movement] + [Style/Quality Tags]
```

### Prompt Formula Example:
> **Prompt:** "Macro close-up shot of a dark-mode code editor displaying glowing syntax-highlighted Python code on an ultra-wide curved OLED monitor. Cinematic camera pan from left to right with soft neon cyan and purple ambient lighting reflecting on dark wood desk. Cinematic 8k, crisp 60fps, photorealistic tech aesthetic."

---

## 3. Standard Production Specifications

### A. YouTube Shorts Format (Vertical)
- **Aspect Ratio:** 9:16 (1080x1920)
- **Duration:** 30–60 seconds (Target 45s)
- **Pacing:** Rapid cut every 2.5–4 seconds
- **Color Palette:** Dark Mode Tech (#0d1117 background, #58a6ff cyan accents, #79c0ff highlights)
- **Voiceover:** Clear, confident male/female developer voice, 140–160 WPM pace
- **Captions:** Center-highlighted kinetic typography (yellow/white bold font)

### B. YouTube Standard Video Format (Horizontal)
- **Aspect Ratio:** 16:9 (3840x2160 or 1920x1080)
- **Duration:** Full breakdown / script spec (3–5 minutes)
- **Pacing:** Structured sections with B-roll transitions every 5–8 seconds
- **Lighting:** Studio soft key light with subtle rim lighting behind monitor

---

## 4. Scene-by-Scene Prompt Templates

### Scene 1: Hook / Problem Statement (0s - 5s)
- **Visual:** Developer typing intently on keycaps, illuminated by glowing terminal/code output.
- **Camera:** Low-angle close-up moving towards hands/keyboard.
- **Lighting:** Moody ambient blue backlight.

### Scene 2: Feature Showcase / Interface Walkthrough (5s - 25s)
- **Visual:** High-definition screen capture or stylized screen animation showing IDE UI, inline AI suggestions, git integration, or extension store.
- **Camera:** Dynamic smooth zoom onto specific code line or sidebar element.
- **Lighting:** Clean ambient workspace light.

### Scene 3: Pros vs Cons / Pricing Verdict (25s - 40s)
- **Visual:** Split screen or side-by-side holographic style card comparing features (Paid tier vs Free/Open-Source tier).
- **Camera:** Static frontal medium shot with sliding transition elements.

### Scene 4: Call to Action & Disclaimer (40s - 45s / end)
- **Visual:** YouTube channel logo `@IDEguide` with animated subscribe badge and link to Blogger post `ideguide.blogspot.com`.
- **Text Overlay:** Standard non-sponsorship disclaimer displayed on screen.

---

## 5. Standard Mandatory Non-Sponsorship Disclaimer

Every video script and blog post generated for **IDE Guide** MUST prominently display or state the following exact disclaimer:

> **"Disclaimer: IDE Guide is an independent technical publication. This content is not sponsored, endorsed, or affiliated with any software vendor or editor developer mentioned above. All reviews and assessments are based strictly on objective developer evaluation."**
