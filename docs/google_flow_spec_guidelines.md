# Google Flow & Visual Video Specification Guidelines

## Overview
This document specifies the standards and guidelines for generating high-quality visual video specifications for Google Flow and AI video creation tools. These specifications are tailored for the **IDE Guide** YouTube Channel (`https://www.youtube.com/@IDEguide`) and Blogger Website (`https://ideguide.blogspot.com/`).

## Daily Production Target
- **Frequency:** 3 Videos Daily (Long-form and YouTube Shorts format)
- **Topic Focus:** Developer IDEs, Code Editors, AI Coding Assistants (e.g., VS Code, JetBrains IntelliJ, Cursor, Zed, Neovim, Windsurf, Fleet, Lapce, Sublime Text).
- **Core Elements:** Good & Bad points, Pricing (Free vs Paid vs Freemium), Recommendation matrix, visual prompt specifications for Google Flow.

---

## 1. Visual Prompt Structure for Google Flow / AI Video Tools
Every visual scene generated in our specifications must follow this strict structured format:

```text
[Camera Shot/Framing] + [Subject & Action] + [Lighting & Environment] + [Aesthetic Style] + [Motion Dynamics]
```

### Prompt Engineering Guidelines:
- **Shot Types:** Close-up on sleek ultra-wide monitor displaying modern code editor UI, macro shots of mechanical keyboard, wide cinematic developer studio workstation, dynamic split-screen comparison.
- **Lighting:** Cyberpunk neon accents (cyan/purple/amber), soft diffused ambient desk lighting, cinematic dark mode aesthetic, realistic glass reflections.
- **Motion:** Slow push-in tracking shot, smooth horizontal pan across IDE sidebar features, rack focus between code preview and terminal execution, energetic dynamic zoom for highlights.
- **Resolution & Aspect Ratio:**
  - YouTube Shorts / TikTok / Reels: Vertical `9:16` (1080x1920)
  - Standard YouTube Video: Horizontal `16:9` (3840x2160 / 1920x1080)

## 2. Video Script & Scene Breakdown Blueprint

Each video specification package generated by IDE Guide includes:
1. **Title Options:** 3 high-CTR options for YouTube.
2. **Shorts / Reel Script (60s):** Fast-paced hook, core pros/cons, pricing, verdict.
3. **Full Video Script (3-5 min):**
   - **Hook (0-15s):** Visual teaser + core developer pain point solved or created by the IDE.
   - **Overview & Target Audience:** Who this IDE is built for.
   - **The Good (Pros):** Key features, AI capabilities, performance benchmarks, extension ecosystem.
   - **The Bad (Cons):** Resource consumption, telemetry/privacy, learning curve, missing features.
   - **Pricing & License:** Clear breakdown (100% Free / Open Source vs Subscription vs Enterprise).
   - **Verdict & Recommendation:** "Who should switch today?"
4. **Google Flow Scene Specifications:** Scene-by-scene timing, voiceover transcript, and exact AI video generation prompts.
