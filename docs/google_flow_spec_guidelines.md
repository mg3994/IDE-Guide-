## Video Format Specifications

### 1. YouTube Shorts / Vertical Video (9:16 Aspect Ratio)
- **Target Duration**: 45–60 seconds
- **Resolution**: 1080x1920 (4K preferred if rendering permits)
- **Pacing**: Fast-cut, high energy, dynamic transitions every 2–4 seconds
- **Structure**:
  1. **Hook (0-5s)**: High visual impact, compelling question or bold claim about the IDE.
  2. **Core Highlight (5-25s)**: Feature demonstration, code syntax highlighting visual, performance metric.
  3. **Good vs Bad (25-45s)**: Clear pros (green highlight) and cons (red highlight).
  4. **Verdict & Pricing (45-55s)**: Free/Paid status, developer suitability recommendation.
  5. **CTA (55-60s)**: Subscribe to @IDEguide & link in bio for AMP blog review.

### 2. YouTube Standard Video (16:9 Aspect Ratio)
- **Target Duration**: 3–5 minutes
- **Resolution**: 1920x1080 / 3840x2160
- **Pacing**: Structured, rhythmic, clean cinematic transitions
- **Structure**:
  1. **Intro & Channel Overview (0-30s)**: Hook, intro visual, disclaimer.
  2. **Feature Deep-Dive (30s-2m)**: Architecture, UI design, extensions, AI capabilities.
  3. **Pros & Cons Evaluation (2m-3m30s)**: Detailed balance sheet (Good vs Bad).
  4. **Pricing & Best Use Cases (3m30s-4m30s)**: Is it worth paying for? Who is it best for?
  5. **Final Verdict & Call to Action (4m30s-5m)**: Rating score, link to `ideguide.blogspot.com`.

## Google Flow Visual & Prompt Guidelines

When generating visual prompts for Google Flow video tools, use structured prompt parameters:

### Visual Style Keywords
- **Environment**: Clean, futuristic developer workspace, sleek dark mode desktop setup, ambient glowing neon accents (cyan/purple/amber).
- **Lighting**: Soft cinematic rim lighting, volumetric background glow, high contrast UI display focus.
- **Camera Movement**: Slow pan left-to-right, smooth dolly zoom into code syntax block, macro lens focus on terminal prompt.
- **Color Palette**: Cyberpunk dark gray (#1e1e2e), electric blue accents, glowing syntax colors (emerald green, coral pink).

### Example Google Flow Scene Prompt Structure
```json
{
  "scene_number": 1,
  "duration_seconds": 5,
  "visual_prompt": "Cinematic close-up shot of a sleek modern IDE code editor interface displaying glowing dark-mode Python syntax. Soft purple and cyan ambient studio lighting reflecting off a clean desk setup. Smooth camera slow-pan left to right. 4k resolution, hyper-realistic depth of field.",
  "overlay_text": "Is THIS the Best New AI Code Editor?",
  "voiceover_script": "If you're still writing code without this AI-powered IDE, you might be losing hours every single day."
}
```

## Standard Content Requirements for Every Review
1. **IDE Name & Version/Platform**: Clear identity of the tool.
2. **Key Capabilities**: Unique features (AI completion, remote dev, extensions, multi-language support).
3. **Good (Pros)**: Speed, usability, feature set, ecosystem.
4. **Bad (Cons)**: Memory usage, price tag, telemetry, steep learning curve.
5. **Pricing Breakdown**: Completely Free, Freemium, Paid Subscription, or Open Source.
6. **Target Audience**: Who benefits most (Web Dev, AI Engineer, Systems Programmer, Beginner).
